# English AI Tutor
English AI Tutor is a comprehensive, AI-powered language learning platform designed to help users improve their English skills through interactive lessons, real-time feedback, and gamified progress tracking. The application leverages Google's Gemini AI to provide personalized evaluations for compositions, comprehension tests, and vocabulary exercises.

Key Features

AI-Powered Evaluation: Utilizes the Gemini 1.5 Flash model to grade user submissions (essays, letters, etc.) and provide detailed, actionable feedback.

Interactive Learning Modules:

Composition: Practice writing essays, letters, and short paragraphs with instant AI scoring.

On-Demand Tests: Generate custom questions and get evaluated on both objective and subjective answers.

Lessons: Structured learning paths for various English topics.

Gamification & Progress:

Streaks: Track daily learning consistency.

Leaderboard: Compete with other users based on learning points.

Progress Tracking: Monitor improvements over time.

Secure Authentication: User registration and login support, including Google OAuth integration.

🛠️ Tech Stack
Frontend
Framework: React (Vite)

Language: TypeScript

Styling: Tailwind CSS, shadcn/ui

State Management & Querying: React Query (@tanstack/react-query)
